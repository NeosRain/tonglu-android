# Fixed launcher icon: Tomato mascot

User direction (2026-10-19): use the existing 番茄酱 character; a concrete, friendly flat portrait, independent of the provisional app name. The earlier abstract paths/book draft was rejected and is not shipped.

`tomato-icon.png` was created with the built-in imagegen tool using this project's `tomato_idle.png` and `tomato_encourage.png` as identity references. It is the editable source artwork; Android does not package this artwork directory. `store-icon-512.png` is an opaque square export without a baked launcher mask.

Production export: `scripts/gen_launcher_icons.py` (Pillow required). It normalizes the portrait into the centered 66dp safe circle of the 108dp adaptive layer, writes the foreground PNG and five legacy density pairs. The launcher supplies its own mask. The app never changes launcher components based on its light/dark setting. Legacy aliases have no launcher filter and only preserve old explicit shortcuts.

## Generation prompt (built-in imagegen)

+Use case: identity-preserve / style-transfer. Asset type: final Android adaptive app icon character FOREGROUND, square 1024px PNG with genuinely transparent background. Reference images: the existing original mascot 番茄酱; preserve this exact character identity: short softly wavy tomato-red/orange bob haircut, amber-gold eyes, small green tomato-leaf hair clip with red tomato and tiny white flower on viewer-right, warm friendly smile, green ribbon at collar, red cape over cream blouse. Primary request: make a beautiful FLAT 2D character PORTRAIT app icon, not an abstract logo. A close head-and-shoulders portrait, facing viewer, slightly playful gentle expression, bright open eyes. Clean rounded silhouette, minimal confident lines, broad flat color areas and at most one cel-shaded shadow tone per area; drastically simplify hair strands, clothing ruffles and decorations. Use the emotional clarity of a friendly anime-game profile icon without copying any existing game's artwork. No full body, no hands, no book, no letters or words, no badge, no particles, no frame, no enclosing tile, no rounded-square mask, no 3D, no painterly textures, no photographic rendering. Center all essential facial features inside the centered Android 66/108 safe circle; whole visible character silhouette fits approximately 64% canvas width and 66% canvas height, with transparent outer margin for system masks. A single polished production icon foreground, not a concept sheet. Outside character must be truly transparent.
